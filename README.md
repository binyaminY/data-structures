# חידון מבני נתונים ואלגוריתמים

אפליקציית חידון אינטראקטיבית לחיזוק ידע במבני נתונים — עץ AVL, ערימה וטבלת גיבוב.

## נושאים

| נושא | שאלות |
|------|--------|
| עץ AVL | 10 |
| ערימה (Heap) | 10 |
| טבלת גיבוב (Hash Table) | 10 |
| השוואה כללית | 4 |

## תכונות

- בחירת נושא ספציפי או כל הנושאים יחד
- בחירת מספר שאלות (5 / 10 / 15 / 20)
- שאלות בסדר אקראי בכל פעם
- הסבר מיידי לאחר כל תשובה
- דף תוצאות עם רשימת שאלות שהוחמצו

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה תיפתח בכתובת [http://localhost:5173](http://localhost:5173)

## בנייה לייצור

```bash
npm run build
```
